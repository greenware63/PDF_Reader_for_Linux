# Feature Parity Matrix: PDF Reader Pro vs. Linux PDF Workstation

This matrix audits every capability advertised on the [PDF Reader Pro Features Catalog](https://www.pdfreaderpro.com/features) against verified source code and automated tests in this repository.

---

## Executive Summary

| Status | Count | Description |
| :--- | :---: | :--- |
| **Supported** | **10** | Fully implemented in the engine/UI with verified automated test coverage. |
| **Partial** | **6** | Implemented with specific specification or UI limitations recorded below. |
| **Not supported** | **37** | Not currently implemented in the engine or UI. |
| **Out of scope** | **5** | Deferred by architectural policy until core document features are complete (AI features). |
| **Unverified** | **0** | *(All features have verified code evidence; external desktop viewer rendering tracked separately in [`docs/EXTERNAL_VIEWER_CHECKLIST.md`](EXTERNAL_VIEWER_CHECKLIST.md))*. |
| **Total Vendor Features Audited** | **58** | Complete feature set from vendor specification catalog. |
| **Architectural Differentiators (Ours)** | **5** | Unique architectural security & fidelity capabilities absent in vendor product. |
